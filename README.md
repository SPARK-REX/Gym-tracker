## 🌟 Overview

**Gym Tracker PWA** is a mobile-first web app built for fast, distraction-free logging in gym environments. It features pre-configured workout split routines, real-time set/rep tracking, offline local storage persistence, and **integrated 1-click YouTube exercise form video tutorials**.

---

## ✨ Key Features

- 🎬 **Dynamic YouTube Form Tutorials**: 1-click `<i class="fab fa-youtube"></i>` video links automatically generated for every exercise to check proper form & technique on YouTube.
- 🏋️ **Pre-Configured Workout Splits**: Pre-loaded routine categories for **Push, Pull, Legs, Abs, and Chest**.
- 📱 **Installable PWA**: Add to Home Screen on iOS and Android devices for native app usage.
- 💾 **Offline Data Persistence**: Saves custom workouts and logs directly in browser `localStorage`.
- 🎨 **Modern Neon UI**: Styled with **Outfit** typography and **Font Awesome 6** icons with `#00ff88` neon highlights.
